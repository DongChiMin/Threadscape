Image → Stitch Path grid (tapestry maker)

Pick a picture (transparent PNGs work best). It is shrunk to a grid, every cell is snapped to the nearest of the 11 floss colours, and the result is printed as rows you can paste into ART / TAP in logic.js (or save as a .txt). Width and height should be multiples of 8 so the picture splits into 8×8 pieces.

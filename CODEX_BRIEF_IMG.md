# Brief: result illustration for the tapestry "Cottage Garden" (STYLE TEST, generate exactly ONE image)

Context: "Stitch Path" is a cozy mobile cross-stitch puzzle. When the player finishes a tapestry, the stitched pixel picture dissolves into a "real" finished artwork, which is then kept in a collection. This run is a STYLE TEST so the game designer can approve the look before we generate every level.

## Task
Use your image generation tool to create ONE square illustration (1024x1024, PNG) and save it as:
  results/cottage.png   (relative to the current folder; create the folder if needed)

Do not edit any other file. Do not create other images. When finished reply with the saved path and one sentence on the style you used.

## Subject (must match the stitched picture's composition)
A small cottage garden scene. Reference layout is a 16x16 pixel grid, each letter one colour; treat it as a composition guide only (the odd teal/green banding in the grass and the colour splits are puzzle artefacts - read them as one grass area):

Legend: R=coral red, G=leaf green, B=sky blue, Y=sunflower yellow, V=violet, P=pink, O=orange, N=brown, T=teal, K=charcoal, .=empty (background)

In words: soft sky with a small white cloud top-left and a warm yellow sun top-right; a cosy cottage centred, orange walls, red-coral roof with a brown chimney, a brown door and two small blue windows; a round green tree on the right with a brown trunk; a grassy foreground with tiny pink, violet and yellow flowers. Keep the same placement as the grid (sun top-right, cottage centre-left, tree right, grass along the bottom quarter).

## Style (this is what we are testing)
Warm storybook illustration, soft painterly gouache texture with gentle paper grain, rounded friendly shapes, soft light from the top-left, calm cosy mood. Palette should stay close to the game's floss colours: coral #E0534A, leaf #5AA05A, sky #4A8FD6, sunflower #F2C230, orange #F08A3C, brown #8B5A3C, pink #EC86AD, violet #8A62C6, with a creamy off-white (#F6EBD3) for light areas. Slight hand-made, embroidery-pattern-original feel. Simple readable shapes so it still works as a small thumbnail.

## Hard rules
- Full-bleed square image, NO border, NO frame, NO text, NO watermark, NO logo, NO people.
- Opaque background (no transparency).
- Do not use a photographic style.
